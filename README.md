# Simple Games — main page

Landing page for the games at https://github.com/simple-games-dev.

Single static `index.html` (no build step). To publish: push to a repo named `main-page`, then
Settings → Pages → Deploy from branch → `main` / root.
Live at `https://simple-games-dev.github.io/main-page/`.

To add a game, copy one `<a class="game">` block in `index.html` and change its link, text and `data-t` filter tags.
